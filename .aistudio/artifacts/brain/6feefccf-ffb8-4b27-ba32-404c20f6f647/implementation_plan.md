# تطبيق مواعيد ومنبه المذاكرة (mawaid)

تطبيق متكامل لإدارة مواعيد الدراسة والتنبيهات وجلسات البومودورو بواجهة عربية كاملة (RTL) مبني بـ Flutter 3.27.1، يدعم تسجيل الصوت وتوليد الكلام باللغة العربية (TTS) واختيار الملفات الصوتية، مع جدولة دقيقة للتنبيهات وسير عمل آلي للبناء عبر GitHub Actions.

## مراجعة المستخدم والقرارات الحاسمة

> [!IMPORTANT]
> تم تأكيد الخيارات الرئيسية بناءً على تفضيلاتك:

- **القرار المؤكد 1 (طبيعة المخرجات)**: تقديم ملفات Flutter الكاملة (`lib/main.dart`، `pubspec.yaml`) مع ملف سير العمل الآلي (`.github/workflows/build.yml`) وخطوات البناء والنشر التفصيلية.
- **القرار المؤكد 2 (الصوت الافتراضي للتنبيه)**: اعتماد تحويل النص إلى كلام باللغة العربية (TTS - "قوم ذاكر يا بطل") كخيار افتراضي أولي للمنبهات الجديدة مع إمكانية التغيير للتسجيل أو الملفات الصوتية.
- **القرار المؤكد 3 (إعدادات البومودورو الافتراضية)**: ضبط المؤقت الافتراضي على 25 دقيقة مذاكرة و 5 دقائق استراحة قصيرة، مع تخصيص كامل في شاشة الإعدادات.

---

## 1. نظرة عامة والمفهوم الأساسي

- **ماذا يقدم التطبيق**: نظام متكامل للمتعلمين والطلاب لتنظيم مواعيد المذاكرة، إطلاق منبهات موثوقة حتى في وضع النوم العميق أو على الهواتف المقيدة للخلفية، وإدارة وقت المذاكرة بتقنية البومودورو مع تتبع الإحصائيات الزمنية.
- **الجمهور المستهدف**: الطلاب والمتعلمون الباحثون عن تركيز عالٍ وإدارة زمنية فعالة بصوت تنبيه مخصص ومحفز باللغة العربية.
- **القيمة المضافة**: موثوقية تشغيل المنبه بدون تداخل الأصوات (صوت واحد نقي من اختيار المستخدم)، والتسجيل المباشر بنبرة تشجيعية أو الذكاء الصوتي (TTS).

---

## 2. تجربة المستخدم والتصميم البصري (RTL)

### التدفقات الرئيسية للمستخدم
1. **الشاشة الرئيسية (Home)**:
   - عرض قائمة البطاقات للمواعيد النشطة والمكتملة مع مؤشرات وقت الاستحقاق ونوع التكرار.
   - شريط علوي (AppBar) يضم اختصارات: البومودورو، الإحصائيات، الإعدادات، ومسح الكل.
   - سحب البطاقة (Dismissible) لليسار لحذف الموعد مع نافذة تأكيد آمنة.
   - أزرار سريعة للتعديل، الحذف، والتشغيل/التعطيل.
   - حالة فارغة (Empty State) جذابة برسوم وأيقونات محفزة عند عدم وجود مواعيد.
2. **إضافة / تعديل موعد**:
   - إدخال عنوان الموعد وملاحظة اختيارية.
   - اختيار نوع التكرار: (مرة واحدة مع التاريخ، كل يوم، أو أيام محددة من الأسبوع).
   - اختيار الوقت بدقة بنظام 12 ساعة (صباحاً/مساءً).
   - منتقي الصوت ثلاثي الأبعاد: ملف صوتي، تسجيل مباشر، أو توليد صوتي (TTS).
3. **شاشة رنين المنبه (Alarm Screen)**:
   - تنطلق كـ Full Screen Activity فوق شاشة القفل.
   - تدرج لوني أحمر ناري نابض مع أنيميشن لأيقونة الجرس.
   - عرض اسم الموعد، الملاحظة، والوقت الحالي بخط عربي كبير.
   - زر "إيقاف" بارز يوقف الصوت فوراً ويغلق الشاشة.
4. **مؤقت البومودورو والإحصائيات**:
   - حلقة تقدم دائرية تفاعلية لعرض الوقت المتبقي لجلسة التركيز أو الاستراحة.
   - أزرار تحكم واضحة (ابدأ / إيقاف مؤقت / إعادة تعيين).
   - شاشة إحصائيات تحسب مجموع دقائق اليوم، إجمالي الدقائق التاريخي، وآخر 20 جلسة مسجلة.
5. **شاشة عن التطبيق والإعدادات**:
   - توثيق اسم المهندس "يوسف أحمد مصطفى"، الإصدار، التبديل للوضع الليلي، وترحيل واستعادة البيانات.

### الهوية البصرية والمظهر
- **اللون الأساسي**: الأزرق المخضر الهادئ (Teal `#00897B` و `#004D40`) لتعزيز التركيز والهدوء.
- **لون التحذير / المنبه**: تدرج أحمر ساطع (`#E53935` إلى `#B71C1C`) لشاشة الرنين.
- **نمط التصميم**: Material 3 مع دعم كامل للاتجاه من اليمين لليسار (`Directionality(textDirection: TextDirection.rtl)`).
- **الوضع الليلي والنهاري**: دعم مرن وديناميكي عبر `ThemeMode`.

## 3. القرارات التقنية ومعمارية الحل

### هندسة التنبيهات الموثوقة (Anti-Overlap Alarm Engine)
- **المشكلة**: في بعض الهواتف (مثل Xiaomi و Vivo)، قد تتداخل أصوات التنبيه إذا شغلت مكتبة `alarm` نغمة النظام مع تشغيل نغمة مخصصة، أو قد يتوقف الصوت بالخلفية.
- **الحل المعتمد**:
  1. تقوم مكتبة `alarm` بجدولة التنبيه باستخدام ملف صامت (`assets/silent.mp3`) لضمان إيقاظ المعالج وفتح الشاشة كاملة (`androidFullScreenIntent: true`).
  2. تتولى شاشة `AlarmScreen` تشغيل الصوت الفعلي حصرياً عبر `audioplayers` بنمط التكرار اللانهائي (`ReleaseMode.loop`)، مع 3 محاولات تدريجية: (صوت المستخدم المحدد -> نغمة النظام -> صوت الإشعار الافتراضي).
  3. النتيجة: صوت واحد فقط نقي ومضمون يشتغل بدون أي صدى أو تكرار.

### محرك الصوت الثلاثي
1. **ملف من الجهاز**: اختيار عبر `file_picker`، ثم نسخه فوراً لمجلد التطبيق الدائم المستقر (`getApplicationDocumentsDirectory`) لضمان عدم فقده لو حُذف الملف الأصلي.
2. **تسجيل مباشر**: واجهة تسجيل بالمايكروفون باستخدام `record`، تعرض عداد الثواني مع زري تسجيل وإيقاف وزر استماع تجريبي قبل الحفظ.
3. **تحويل النص لكلام (TTS)**: استخدام `flutter_tts` مع لغة `ar-EG`، كتابة العبارة التحفيزية وتوليد ملف صوتي دائم لها، مع إمكانية ضبط السرعة والنبرة والاستماع المسبق.

### ترحيل البيانات القديمة (Legacy Migration Engine)
- استرجاع تلقائي عند بدء التشغيل للمفاتيح القديمة:
  - `appointments` و `appointments_v1` حتى `appointments_v5` -> دمجها وحفظها في `appointments_v6`.
  - `sessions` و `sessions_v1` حتى `sessions_v5` -> `sessions_v6`.
  - `dark_mode` و `dark_mode_v1..v5` -> `dark_mode_v6`.
  - `pomodoro_settings` و `pomodoro_settings_v1..v5` -> `pomodoro_settings_v6`.
- معالجة البيانات المحفوظة بأمان عبر `DateTime.tryParse` و `whereType<Map<String, dynamic>>()` لمنع أي انهيار في التطبيق.

## 5. مخرجات التنفيذ

1. **`lib/main.dart`**: كود مصدري نظيف ومحكم في ملف واحد يحتوي على كافة الشاشات، مزود الحالة `ChangeNotifier`، معالجة الصوت الثلاثية، نظام الترحيل الآمن، والدعم الكامل للغة العربية.
2. **`pubspec.yaml`**: ملف الاعتماديات المحدث والمحدد بإصدارات متوافقة ودقيقة.
3. **`.github/workflows/build.yml`**: سير عمل جاهز ومختبر يقوم بتوليد `silent.mp3` عبر `ffmpeg` وبناء الـ APK Release ورفعه كـ Artifact للتنزيل المباشر.
4. **دليل البناء والنشر**: خطوات واضحة خطوة بخطوة للتشغيل محلياً أو رفعه على GitHub.
